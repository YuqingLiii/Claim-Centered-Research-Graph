## 3. Why this is not a weakening — the audit

**The single added field, verbatim:**

```lean
rho_hook : ∀ n d, d < K n →
  ∃ (L : ℕ) (t : ℕ → ℕ), IsColumnData L t d ∧ F.rho n d = rtopHook (2 * n) d L t
```

1. **It is definitional, not quantitative.** It says only that the paper's
   `ρ_d = max_{θ⊢d} r_top(2n,d,θ)` (eq:rtop) is *attained* at some shape and that the hook-length
   formula evaluates that shape's `r_top = q^d f^θ/(d! f^{(q−d,θ)})` as the explicit product. It
   contains no inequality and no constant. Everything numeric it replaced is now proved.
2. **Its two external inputs are named.** (i) The Frame–Robinson–Thrall hook-length formula, applied
   to `λ = (q−d,θ)` — whose first-row hooks are `q−d−c+1+θ'_c` and whose remaining hooks are exactly
   the hooks of `θ`, which is why the ratio telescopes to the displayed product. (ii) A maximum over
   the finite nonempty set of partitions of `d` is attained. Mathlib v4.31.0 has `YoungDiagram` and
   **no** hook-length formula, **no** Specht modules, **no** Littlewood–Richardson, **no** Pieri
   rule (verified 2026-08-17), so (i) cannot be proved here and is cited by name in
   `SE/Interface.lean` and `SE/Trust.lean` §B2.
3. **The shape hypothesis is weaker than "is a partition", so the theorem proved is stronger.**
   `IsColumnData L t d` asks only: `t i ≥ 1` for `i < L`, `t i = 0` beyond, `t i ≤ t 0`, and
   `Σ_{i<L} t i = d`. Every conjugate of a partition of `d` satisfies it, so the field is implied by
   the paper's definition; and the envelope is proved for *all* such `t`, not only for conjugates.
4. **The conclusions did not shrink.** `rho_le`'s conclusion is the tier-1 conclusion with the
   abstract `F.rhoConst` replaced by the explicit `4` — strictly more informative. `rho_ge_one`'s
   conclusion is unchanged.
5. **One scope narrowing, declared.** Tier 1 assumed `1 ≤ F.rho n d` for *all* `(n,d)`; the tier-2
   theorem proves it for `d < K n`. Both of its two call sites already carry that hypothesis —
   `SE.denom.block_le` has `hd : d < K n`, and `SE.denom.Phi.legal.tame.composition` has
   `hjK : j < K n − 1` — so the tier-1 chain is unaffected. This narrows what is *assumed* (tier 1
   assumed `1 ≤ ρ_d` at points, e.g. `n = 0`, where `ρ_d` is not even defined by eq:rtop); it does
   not narrow what is *concluded*. `theoremB` and every `composition` theorem retain their exact
   tier-1 statements, except that the constant in `denom.Claim`, `br.Claim` and `goal.Claim` is now
   the explicit `SE.rhoConst` instead of a universally-quantified carrier field.
6. **Non-vacuity is preserved and is now harder to satisfy.** The three `SelfTest` models used
   `ρ ≡ 1`, which is *not* a hook value for `d ≥ 1`; they now carry
   `modelRho n d = r_top(2n,d,(d))`, the genuine single-row hook value, and still satisfy `Cited`
   together with H1–H4 (`hypotheses_consistent`, `hypotheses_consistent_live`,
   `hypotheses_consistent_channels`), with `channelFrame` still having strictly positive channel
   norms. The end-to-end plumbing checks `liveSectorFrame_goal` and `channelFrame_goal` still
   typecheck, i.e. `tame → denom → br → goal` still composes.

## 5. What I could NOT discharge, and why

**Target 6 — the two-sided ω range `j/q ≤ ω ≤ j/(q−2j)` (fields `omega_le`, `omega_pos`): NOT
attempted in Lean, by a time/risk decision, not by an obstruction.** I did the mathematics on paper
and record it here so the next session starts from it rather than from scratch:

- In conjugate coordinates, with `h_c = q−j−c+1+θ'_c` (first-row hooks of `λ = (q−j,θ)`) and
  `L = θ₁`, the hook-length formula gives
  `p₀ = f^{(q−j−1,θ)}/f^{(q−j,θ)} = (1/q)·∏_{c=1}^{q−j} h_c / ∏_{c=1}^{q−j−1}(h_c − 1)`
  (the `θ`-part hooks cancel; the `λ⁻` first-row hooks are exactly `h_c − 1`).
- Two regroupings are useful. Pairing `h_{c+1}` against `h_c − 1` leaves only `L` nontrivial
  factors, so no telescoping is needed but the bounds are awkward:
  `p₀ = (1/q)·h_1·∏_{c=1}^{L}(q−j−c+θ'_{c+1})/(q−j−c+θ'_c)`.
  Pairing `h_c − 1` against `h_c` needs one telescoping over `c = L+1 … q−j−1` and gives the form
  the bounds want: `1/p₀ = q/(q−j−L)·∏_{c=1}^{L}(1 − 1/h_c)`.
- From the second form: **lower bound** `ω ≥ j/q` follows from `θ'_c ≥ 1` (so `h_c ≥ q−j−c+2`),
  which telescopes to `∏(1−1/h_c) ≥ (q−j−L+1)/(q−j+1)`, and then
  `q²(s+1) ≥ s(q+j)(q−j+1)` with `s = q−j−L ≤ q−j−1` is elementary. **Upper bound**
  `ω ≤ j/(q−2j)` follows from `θ'_c ≤ θ'_1` (so `h_c ≤ q−j−c+1+θ'_1`), which telescopes to
  `∏(1−1/h_c) ≤ (A−L+a)/(A+a)` with `A = q−j`, `a = θ'_1`, and reduces to
  `A(j² − La) + j²(a − L) ≥ 0`; that holds because a partition of `j` satisfies `j ≤ L·a` and
  `a + L ≤ j+1` (hence `La ≤ (j+1)²/4 ≤ j²`) and `A ≥ 5j` on the paper's window `n ≥ 3j`, with
  **equality exactly at `j = 1`** (which is why no lossy step, e.g. `∏(1−x) ≤ e^{−Σx}`, may be used).
  All four facts about the shape are already available as
  `IsColumnData.{pos, le_head, le_length_mul_head, head_add_length_le}`, which I proved for this
  purpose.
- Two pieces of Lean work remain: (a) the telescoping product identity over `Finset.Ico L (q−j−1)`
  (ℝ is not a multiplicative group, so `Finset.prod_range_div` does not apply directly); and
  (b) the `Cited` wiring, which needs a *carrier* field exposing each sector's shape `θ` plus an
  `omegaS`/`rtopS` hook-identification field, and a rework of all three `SelfTest` models, whose
  H1/H2/H3 proofs currently depend on `omegaS n j s` being *exactly* `j/(2(n−j))`. I stopped rather
  than risk leaving the tree red; this is recorded as `SE.formal.t2` frontier `task-003`.
