## 3. The mathematics, as Lean now has it

### 3.1 `p₀` by its hook ratio, and the reduction (`SE/Support/Omega.lean`, task-003)

With `λ = (q−j,θ)`, `A = q−j`, and the conjugate coordinates `t i = θ'_{i+1}` of `SE.IsColumnData`:

* `SE.rowHook q j t i = q−j−i+θ'_{i+1}` is the first-row hook `h_c` at `c = i+1`; the hooks of the
  rows below the first are exactly the hooks of `θ` and cancel in the ratio; the first-row hooks of
  `λ⁻ = (q−j−1,θ)` are the `h_c − 1`. Hence the **definition**
  `SE.p0Hook q j t = (1/q)·∏_{c=1}^{q−j} h_c / ∏_{c=1}^{q−j−1}(h_c − 1)`, and
  `SE.omegaHook q j t = (1 − p₀)/p₀` (paper eq:parameters-can, verbatim).
  This is the **only** external citation in the file: the Frame–Robinson–Thrall hook-length formula,
  the same citation `rho_isGreatest` makes.
* `SE.rowHook_top`: `h_{q−j} = 1` (its column is empty), so the numerator loses its top factor and
  `1/p₀ = q·∏_{c=1}^{q−j−1}(1 − 1/h_c)` (`SE.p0Hook_eq_prod`).
* **The telescoping step, over `Finset.Ico θ₁ (q−j−1)`** (`SE.p0Hook_eq_inv`): beyond the shape
  `θ'_c = 0`, so `1 − 1/h_c = (A−c)/(A−c+1)`, and the product collapses to `1/(A−θ₁)`. What is left
  is the form the bounds want:
  `1/p₀ = q/(q−j−θ₁)·∏_{c=1}^{θ₁}(1 − 1/h_c)`, hence `ω = that − 1` (`SE.omegaHook_eq`).
  The two general telescoping identities over `ℝ` live in the new `SE/Support/Telescope.lean`
  (`ℝ` is not a multiplicative group, so `Finset.prod_range_div` does not apply; the nonvanishing
  hypothesis is explicit and the proofs are inductions).

### 3.2 The two majorants — and why neither may be lossy

* **Lower** (`SE.prod_ge_lower` → `SE.le_omegaHook`): `θ'_c ≥ 1` gives `h_c ≥ A−c+2`, so
  `∏(1−1/h_c) ≥ (A−θ₁+1)/(A+1)` by a telescoping product; `j/q ≤ ω` then reduces to the polynomial
  `q²(s+1) ≥ (q+j)(A+1)s` with `s = A−θ₁ ∈ [1, A−1]`, i.e. `q² ≥ s(q+j−j²)`, which holds with room
  because `j ≤ j²` and `s ≤ q−j−1` (`SE.omega_lower_core`).
* **Upper** (`SE.prod_le_upper` → `SE.omegaHook_le`): `θ'_c ≤ θ'_1 = a` gives `h_c ≤ A−c+1+a`, so
  `∏(1−1/h_c) ≤ (A+a−θ₁)/(A+a)`; `ω ≤ j/(q−2j)` then reduces to
  `A(j² − θ₁a) + j²(a − θ₁) ≥ 0` (`SE.omega_upper_core`), which holds because a partition of `j`
  satisfies `a + θ₁ ≤ j+1` (`SE.IsColumnData.head_add_length_le`, so `4θ₁a ≤ (j+1)² ≤ 4j²`) and
  because `A ≥ 5j` on the manuscript's window `n ≥ 3j`, `q = 2n`.
* **Equality holds at `j = 1`** (there `a = θ₁ = 1` and both sides of the upper bound agree:
  `ω = 1/(q−2)` exactly), which is precisely why a step such as `∏(1−x_c) ≤ e^{−Σx_c}` is
  inadmissible — it would lose the boundary case the manuscript's range is tight at. Neither
  majorant used above loses anything at `j = 1`.
* Window: everything is stated for `1 ≤ j`, `6j ≤ q`, i.e. the paper's own `j = k−1 ≥ 1` and
  `n ≥ 3j` at `q = 2n`.

### 3.3 `ρ_j` is a genuine maximum (`SE/Support/Hook.lean`, task-004)

`rtop_le_rho` needs the half of eq:rtop that tier 2a did not assume: that `ρ_j` **dominates** every
shape. Rather than assume it, tier 2b proves the maximizer is explicit:

* `SE.prod_le_prod_rowShape`: with `S_i = θ'_1+…+θ'_i`, each factor obeys
  `1 + θ'_{i+1}/(A−i) ≤ (A−S_i+1)/(A−S_{i+1}+1)` — true because `S_{i+1} ≥ i+1` (every column inside
  the first row is nonempty) — and the majorant telescopes to `(A+1)/(A−d+1)`, which is the single
  row's own value (`SE.prod_rowShape`).
* Hence `SE.rtopHook_le_rowShape` and
  `SE.isGreatest_rtopHookSet : d < n → IsGreatest (rtopHookSet n d) (rhoHook n d)`, with
  `rhoHook n d = r_top(2n,d,(d))`.

So the interface can assume the *stronger* `IsGreatest` form and still be satisfiable — the models
witness it by carrying exactly the row shape.
