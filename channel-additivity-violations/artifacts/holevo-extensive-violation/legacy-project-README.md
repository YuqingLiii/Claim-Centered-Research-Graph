# Size of classical-capacity additivity violations (the Hastings gap)

Statement: how large can Delta = S_min(N1) + S_min(N2) - S_min(N1 tensor N2) be? Extensive form (Hayden–Penington arXiv:2012.07861, Eq. (11)): do channel sequences with qubit-linear dimensions and Delta(n) >= C n exist?
Status: Hastings (arXiv:0809.3972) proved Delta > 0 exists; the 18-year record remains below log 2 (one bit), independent of channel size. Renyi alpha>1: extensive gaps known. Private information: extensive superadditivity known. Commuting-operator framework: arbitrarily large violations (Collins–Youn). The tensor-product von Neumann case is open in BOTH directions.
HP dichotomy: either extensive violations exist, or an almost-basis of exp(S_BH - O(1)) disentangled black-hole microstates exists.
Also open: explicit (derandomized) counterexamples; whether additivity holds in low dimensions.
