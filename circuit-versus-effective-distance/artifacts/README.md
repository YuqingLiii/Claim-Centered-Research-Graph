# Proofs and historical computation packages

Proofs, amendments, definitions, counterexamples and logs are preserved here.
All copied files have recorded SHA-256 hashes in the migration manifest.

Programs embedded in hash-bound historical log packages remain beside their
inputs and outputs. Moving them to a new runnable location would change the
historical package; any future runnable adaptation must be separately named and
must distinguish new outputs from archived ones. No solver was run by this migration.

Historical documents retain their original internal paths and hashes. Use
[PATH_MAP.json](../../gross-code-optimal-circuit-distance/artifacts/history/PATH_MAP.json) to translate those paths to this layout.
