## 5. The common promise problem

Let `I` encode explicit binary CSS check matrices `(H_X,H_Z)`, a positive integer `d`, the required single-ancilla check CNOTs and allowed local orders, and optionally a depth bound `T`. The canonical lead ruling defines a conflict exactly when two simultaneous CNOTs share a data or ancilla qubit. `Legal(I,M)` requires every required CNOT exactly once, an allowed local order for each check, qubit-sharing conflict freedom, and the depth limit when supplied.

Let `P(I)` mean that syntax is valid, the CSS code has at least one logical qubit, and its full static distance is exactly the supplied `d`. The frozen promise pair is

```text
YES = { I : P(I) and exists legal M with d_eff(I,M) = d },
NO  = { I : P(I) and every legal M has d_eff(I,M) < d }.
```

The standard terminal-residual catalogue contains a singleton data column for every physical qubit in each CSS sector. A minimum static logical of weight `d` is therefore a combination of `d` singleton columns. For every schedule on a promised instance,

```text
d_eff(I,M) <= d_static(I) = d,
```

so on promise

```text
d_eff(I,M) = d  iff  d_eff(I,M) >= d.
```

Upper membership uses the total separator

```text
L_>= = { syntactically valid I : exists legal M with d_eff(I,M) >= d }.
```

It never verifies `P(I)`. Off-promise behavior is merely a total language convention. Both hardness proofs instead map every valid source string, including NO strings and explicit malformed/constant branches, to a promised target instance. Thus their Karp maps satisfy

```text
x in A      => f(x) in YES,
x not in A  => f(x) in NO,
and P(f(x)) holds in both cases.
```

This is the shared total promise-preserving polynomial-time many-one convention required for the words NP-complete and `Sigma_2^P`-complete.
