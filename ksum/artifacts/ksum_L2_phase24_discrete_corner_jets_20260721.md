## Decision

**Decision B — scoped obstruction.**  The discrete corner transfer matrix does close exactly, but
the most direct corner-to-normal matching does not close with bounded total variation and
nonnegligible `C_t=1` mass.

For a bounded corner `(r,u)` with unsplit filler `(0,N-r-u)`, every exact orbit row factors into a
bounded local falling-factorial kernel and a filler vector `(N-r-u)_c`.  After division by the
common row scalar `(N)_c`, the filler vector is exactly a polynomial jet in the query index `c`:

```text
(N-m)_c/(N)_c = (N-c)_m/(N)_m,       m=r+u.              (24.1)
```

In particular, the label jump at `C_t=1` is the endpoint `s=2` of the exact family which replaces
an unsplit slot `(0,s)` by `(1,s-1)`.  Its local generating function is the pure quadratic jet
`-(z-w)^2`.  For general `s`, the same jump is

```text
-(z-w)^2 sum_{j=0}^{s-2}(1+z)^(s-2-j)(1+w)^j.            (24.2)
```

Thus the corner and the normal layer really do share one exact transfer family; there is no type
mismatch between them.

However, the degree-`<D` one-slot rows force the coefficients of any signed combination of these
jumps to annihilate all falling-factorial polynomials in `s-2` through degree `D-3`.  Representing
the `s=2` evaluation functional using only `s=Theta(N)` nodes is an extrapolation across a fixed
macroscopic gap.  A Chebyshev polynomial gives an `exp(Omega(D))` lower bound on its coefficient
norm.  At `D=Theta(sqrt N)`, bounded total variation therefore forces the `C_t=1` coefficient to be
`exp(-Omega(sqrt N))` up to a polynomial factor.

So a finite corner jet is a legitimate source term, but it cannot jump directly to the
macroscopic one-unit-opening normal sector while retaining constant mass.  This does **not**
obstruct the full stratified node: intermediate `s` scales, unpaired orbit combinations, or a
construction in which the `C_t=1` mass vanishes can evade the scoped argument.

## 1. Exact corner row matrix

Use the unnormalized pair kernel used by the exact finite engine:

```text
P_{a,b}(r,u)=(r)_a(u)_b+(r)_b(u)_a.                      (24.3)
```

Its exponential generating function is

```text
E_{r,u}(z,w)
 = (1+z)^r(1+w)^u+(1+z)^u(1+w)^r
 = sum_{a,b>=0} P_{a,b}(r,u) z^a w^b/(a!b!).             (24.4)
```

Let

```text
H_{r,u}^{(N)} = {(r,u),(0,n)},
m=r+u,   n=N-m,
1<=r<=u,   m=O(1).                                      (24.5)
```

Write `M_{a,b}=P_{a,b}(r,u)` for `a,b>0` and
`U_c=P_{0,c}(r,u)=(r)_c+(u)_c` for `c>=1`.  Since

```text
P_{a,b}(0,n)=0                   if a,b>0,
P_{0,c}(0,n)=(n)_c               if c>=1,                (24.6)
```

the restriction of every actual `rho<=2` orbit row is the following exact block matrix:

| row type | value on `H_{r,u}^{(N)}` |
|:---|:---|
| constant | `1` |
| one mixed slot pattern `(a,b)`, `a,b>0` | `M_{a,b}` |
| one one-sided pattern `(0,c)` | `U_c+(n)_c` |
| two mixed patterns | `0` |
| mixed `(a,b)` and one-sided `(0,c)` | `M_{a,b}(n)_c` |
| two one-sided patterns `(0,c),(0,d)` | `U_c(n)_d+U_d(n)_c` |

These are exactly the rows generated by `moment_row` in
`ksum/tools/ksum_l2p14_target_scale_sweep.py`; row-dependent nonzero normalization factors have not
been restored because they do not change an annihilating kernel.

Equation (24.1) follows from the factorial identity

```text
(N-m)_c (N)_m = (N)_c (N-c)_m.                           (24.7)
```

For every fixed corner total `m`, the normalized filler dependence is therefore not an infinite
formal series: it is an exact degree-`m` polynomial in `c`.  A bounded collection of corner totals
has a finite exact query-jet transfer matrix.

## 2. The `C_t=1` atom

There is exactly one legal orbit with `C_t=1`:

```text
H_+^{(2)} = {(1,1),(0,N-2)}.                             (24.8)
```

For its corner slot,

```text
M_{1,1}=2,
M_{a,b}=0 for all other a,b>0,
U_1=2,
U_c=0 for c>=2.                                         (24.9)
```

Hence its mixed/one-sided transfer column is

```text
T_{(1,1);c}(H_+^{(2)})=2(N-2)_c,
T_{(a,b);c}(H_+^{(2)})=0 for (a,b)!=(1,1).               (24.10)
```

The natural same-total NO atom is

```text
H_-^{(2)} = {(0,2),(0,N-2)}.                             (24.11)
```

At the local slot, its difference from (24.8) is

```text
E_{1,1}(z,w)-E_{0,2}(z,w)=-(z-w)^2.                     (24.12)
```

Thus the YES/NO label jump is a pure degree-two local jet:

```text
Delta P_{1,1}=+2,
Delta P_{0,2}=-2,
Delta P_{a,b}=0 otherwise.                              (24.13)
```

The full two-slot transfer is this two-entry vector tensored with `(N-2)_c`.  After the common
normalization `(N)_c`, the filler factor is the exact quadratic

```text
(N-2)_c/(N)_c=(N-c)(N-c-1)/(N(N-1)).                    (24.14)
```

This proves that the `C_t=1` atom is a genuine discrete second-order corner jet, rather than an
unresolved infinite collection of corner moments.

## 3. Exact corner-to-normal jump family

For every `2<=s<=N-1`, compare the same-filler orbit pair

```text
H_+^{(s)} = {(1,s-1),(0,N-s)},     C_t=s-1,
H_-^{(s)} = {(0,s),(0,N-s)},       C_t=0.                (24.15)
```

Put `A=1+z`, `B=1+w`.  The exact local generating-function difference is

```text
Delta_s(z,w)
 = A B^(s-1)+B A^(s-1)-A^s-B^s
 = -(A-B)^2 sum_{j=0}^{s-2} A^(s-2-j)B^j
 = -(z-w)^2 sum_{j=0}^{s-2}(1+z)^(s-2-j)(1+w)^j.        (24.16)
```

At `s=2`, (24.16) is exactly (24.12).  At `s=Theta(N)`, opening one unit creates
`C_t=s-1=Theta(N)`, the Phase-23 normal scale.  Therefore (24.16) is an exact discrete transfer
from the corner endpoint to the target normal layer.

If `Delta_s(a,b)` denotes a coefficient of (24.16), the complete orbit-row difference is

```text
rho=1:  Delta_s(a,b),
rho=2:  Delta_s(a,b) P_{c,d}(0,N-s)
       +Delta_s(c,d) P_{a,b}(0,N-s).                    (24.17)
```

Since the filler kills mixed patterns, the only nonzero mixed/one-sided block is

```text
T_{(a,b);c,s}=Delta_s(a,b)(N-s)_c.                       (24.18)
```

This establishes exact type compatibility.  It does not yet give a bounded-norm matching.

## 4. Falling-factorial moment obstruction to a direct macroscopic match

The one-sided local rows already expose the conditioning.  For `a>=2`, direct subtraction gives

```text
Delta_s(0,a)
 = (s-1)_a-(s)_a
 = -a(s-1)_(a-1),                                      (24.19)
```

while

```text
Delta_s(1,1)=2(s-1).                                    (24.20)
```

Consider a signed combination of paired jumps

```text
W=sum_s lambda_s (delta_{H_+^(s)}-delta_{H_-^(s)}).      (24.21)
```

If it annihilates all one-slot rows of degree `<D`, then (24.19)-(24.20) imply

```text
sum_s lambda_s (s-1)_k=0,       1<=k<=D-2.              (24.22)
```

Set

```text
t=s-2,       mu_s=(s-1)lambda_s.                         (24.23)
```

Then (24.22) is equivalent to

```text
sum_s mu_s (t)_j=0,             0<=j<=D-3.              (24.24)
```

Because falling factorials form a basis, (24.24) holds for every polynomial in `t` of degree at
most `D-3`.

Now retain the corner source `s=2`, where `t=0` and `mu_2=lambda_2`, and suppose all other jumps
are macroscopic:

```text
alpha N <= s <= beta N,
0<alpha<beta<=1,                                      (24.25)
```

with fixed `alpha,beta`.  Their `t` coordinates lie in an interval `[A_N,B_N]` separated from
zero by `Theta(N)`.  Let `d=D-3` and choose the Chebyshev extrapolant

```text
Q_d(t)=T_d((2t-A_N-B_N)/(B_N-A_N))
       /T_d(-(A_N+B_N)/(B_N-A_N)).                       (24.26)
```

It has `Q_d(0)=1` and

```text
sup_{t in [A_N,B_N]} |Q_d(t)|
 <= 1/|T_d((A_N+B_N)/(B_N-A_N))|
 = exp(-Omega_alpha,beta(d)).                            (24.27)
```

Insert (24.26) in (24.24).  It gives

```text
sum_{macro s}|mu_s|
 >= |lambda_2| exp(Omega(D)).                            (24.28)
```

Since `s-1<=N`,

```text
sum_{macro s}|lambda_s|
 >= |lambda_2| exp(Omega(D))/N.                          (24.29)
```

The YES atoms in (24.21) are distinct for distinct `s`, so the total variation of (24.21) is at
least `sum_s|lambda_s|` (and is exactly twice that quantity when the paired NO atoms are also
distinct and no cancellations occur).  Consequently any such direct match with bounded total
variation satisfies

```text
|lambda_2| <= N exp(-Omega(D))
             = exp(-Omega(sqrt N))                       (24.30)
```

at `D=Theta(sqrt N)` (absorbing the polynomial factor into the exponent).

This is an exact-row obstruction, not a continuum heuristic.  It uses only a subset of the rows;
the two-slot filler constraints in (24.18) can only add obligations.

## 5. A second exact check: fixed `C_t` corners cannot self-cancel `C_t=1`

Let a signed orbit measure be supported on `0<=C_t<=M`, with `M` fixed.  The actual orbit span
contains every polynomial in `Y=C_t` of weighted degree below `D`.  For `D>2M`, the polynomial

```text
Q_M(Y)=Y product_{k=2}^M (Y-k)/(1-k)                     (24.31)
```

has weighted degree `2M<D`, equals one at `C_t=1`, and equals zero at every other integer
`C_t` in the support range.  Because the legal `C_t=1` orbit is unique, exact annihilation forces
its coefficient to be zero.

Therefore no fixed `C_t=O(1)` corner sector can absorb a nonzero `C_t=1` source internally as
`D` grows.  Some growing `C_t` sector is mandatory.  Combining this fact with (24.30) shows that a
single direct jump from bounded corners to `C_t=Theta(N)` paired openings is also insufficient at
constant corner mass.

## Scoped conclusion

The Phase-23 statement that the corner requires a discrete jet can now be made exact.  The
`C_t=1` jump is a second-order local jet coupled to a quadratic filler jet, and it belongs to the
same exact algebraic family as `C_t=Theta(N)` one-unit-opened normal atoms.  Nevertheless, exact
falling-factorial moments turn direct corner-to-macroscopic matching into exponentially ill-
conditioned polynomial extrapolation.  A bounded-total-variation construction with nonnegligible
`C_t=1` mass must use additional strata or a different, unpaired mechanism.

This is a scoped Decision B, not a refutation of the controlling node.  No `PROVED`,
`CERTIFIED*`, or `REFUTED` status is claimed.
